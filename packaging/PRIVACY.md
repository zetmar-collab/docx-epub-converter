## English

### What this app does

DOCX EPUB Converter is an offline desktop application. It reads Microsoft Word
`.docx` files and cover images that **you** select, and writes EPUB 3 ebook
files to a location **you** choose.

### Data we collect

**None.** The publisher does not collect, receive, transmit, store or sell any
personal data. There is no account, no telemetry, no analytics, no advertising
and no crash reporting.

### Data processed on your device

All processing happens locally on your computer. The app never uploads your
documents anywhere.

| Data | Purpose | Where it is stored |
|---|---|---|
| The `.docx` file you select | Read to extract text, images and structure | Not copied; read in memory |
| The cover image you select | Embedded into the generated EPUB | Not copied; read in memory |
| Ebook metadata you type (title, author, publisher, year, ISBN, description) | Written into the EPUB you generate | Inside the EPUB file you create |
| Author, publisher, year and language of your last conversion | Pre-filled on next launch as a convenience | `%LOCALAPPDATA%\DocxEpubConverter\config.json` on your PC |
| Last-used folder paths | Reopen file dialogs where you left off | Same config file |
| HTML preview of the converted book | Shown when you click "Preview in browser" | Your system temporary folder |

You can delete the settings file at any time; the app recreates it with
defaults. Uninstalling the app from Windows removes its data.

### Network access

The app makes no network connections of its own. Two actions can open your
default web browser, and only when you explicitly click them:

- the ISBN help button, which opens the Polish National Library's free ISBN
  registration site (`e-isbn.pl`);
- the "Preview in browser" button, which opens a local file from your temporary
  folder.

Those websites are governed by their own privacy policies.

### Optional third-party component

EPUB validation uses **EpubCheck** (W3C, BSD licence), which runs locally and
requires a Java runtime. If Java is not installed, validation is skipped and
conversion still works. EpubCheck makes no network connections during
validation.

### Children

The app is a productivity tool, is not directed at children, and collects no
data from anyone.

### Changes

If this policy changes, the updated version will be published at the same URL
with a new "Last updated" date.

## Polski

### Do czego służy aplikacja

DOCX EPUB Converter to aplikacja desktopowa działająca offline. Odczytuje pliki
Microsoft Word `.docx` oraz obrazy okładek, które **Ty** wskazujesz, i zapisuje
pliki ebooków EPUB 3 w lokalizacji, którą **Ty** wybierasz.

### Jakie dane zbieramy

**Żadnych.** Wydawca nie zbiera, nie otrzymuje, nie przesyła, nie przechowuje
ani nie sprzedaje żadnych danych osobowych. Aplikacja nie ma kont użytkownika,
telemetrii, analityki, reklam ani raportowania awarii.

### Dane przetwarzane na Twoim urządzeniu

Całe przetwarzanie odbywa się lokalnie. Aplikacja nigdy nie wysyła Twoich
dokumentów w żadne miejsce.

| Dane | Cel | Gdzie są przechowywane |
|---|---|---|
| Wybrany plik `.docx` | Odczyt tekstu, obrazów i struktury | Nie jest kopiowany; odczyt w pamięci |
| Wybrana okładka | Osadzenie w wygenerowanym EPUB | Nie jest kopiowana; odczyt w pamięci |
| Wpisane metadane (tytuł, autor, wydawca, rok, ISBN, opis) | Zapis do tworzonego pliku EPUB | Wewnątrz utworzonego pliku EPUB |
| Autor, wydawca, rok i język z ostatniej konwersji | Wygodne wypełnienie pól przy kolejnym uruchomieniu | `%LOCALAPPDATA%\DocxEpubConverter\config.json` na Twoim komputerze |
| Ostatnio używane ścieżki folderów | Otwieranie okien dialogowych w tym samym miejscu | Ten sam plik konfiguracyjny |
| Podgląd HTML skonwertowanej książki | Wyświetlany po kliknięciu „Podgląd w przeglądarce” | Folder tymczasowy systemu |

Plik ustawień możesz usunąć w dowolnym momencie — aplikacja odtworzy go z
wartościami domyślnymi. Odinstalowanie aplikacji z systemu Windows usuwa jej
dane.

### Dostęp do sieci

Aplikacja nie nawiązuje własnych połączeń sieciowych. Dwie akcje mogą otworzyć
Twoją domyślną przeglądarkę — wyłącznie po Twoim kliknięciu:

- przycisk pomocy ISBN, otwierający serwis bezpłatnej rejestracji ISBN
  Biblioteki Narodowej (`e-isbn.pl`);
- przycisk „Podgląd w przeglądarce”, otwierający lokalny plik z folderu
  tymczasowego.

Te witryny podlegają własnym politykom prywatności.

### Opcjonalny komponent zewnętrzny

Walidacja EPUB korzysta z **EpubCheck** (W3C, licencja BSD), który działa
lokalnie i wymaga środowiska Java. Jeśli Java nie jest zainstalowana, walidacja
jest pomijana, a konwersja nadal działa. EpubCheck nie łączy się z siecią
podczas walidacji.

### Dzieci

Aplikacja jest narzędziem produktywności, nie jest kierowana do dzieci i nie
zbiera danych od nikogo.

### Zmiany

W razie zmiany niniejszej polityki zaktualizowana wersja zostanie opublikowana
pod tym samym adresem z nową datą „Ostatnia aktualizacja”.
